Resume flow

  1. New chat: insert a conversations row and an eve_sessions row, return the conversation id.
  2. Persist while streaming: upsert each event into session_events and advance stream_index.
  3. Return: load the latest active session, then call useEveAgent({ initialSession, initialEvents, resume: true }).
  4. Expired session: mark it expired and open a new eve_sessions row in the same conversation. The agent re-reads foundations and frameworks, not old chat.
